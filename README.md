## About

웨이브톤 스튜디오는 단순히 악기를 배우는 공간이 아니라, 실제 음악 제작이 이루어지는 환경에서 음악을 경험할 수 있는 공간입니다.

레코딩 스튜디오 수준의 장비와 빈티지 악기, 앰프들이 준비되어 있습니다.

## Lesson

- **Electric Guitar** — 풍부한 사운드를 직접 경험하며 배우는 일렉 기타 개인 레슨
- **Recording** — 녹음·믹싱. 레코딩 스튜디오 수준의 마이크와 장비
- **Ensemble** — 밴드 합주. 함께 연주하며 음악을 완성하는 시간
